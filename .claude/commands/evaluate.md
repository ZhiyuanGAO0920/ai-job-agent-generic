# /evaluate — 单岗位四维评估

## 用法

```text
/evaluate <JD 文本 或 URL>
```

## 执行步骤

1. **加载上下文**：读取 `cv.md` + `knowledge/` 四个文件（若尚未加载）。
2. **红线检查**：按 `04-job-evaluation.md` 第一步，先核对候选人风险红线（地点 / 学历 / 岗位性质 / 合法性）。命中红线 → recommend=false 并标 level=red 风险，如实展示。
3. **四维评分**：按第二步，对技能(35%) / 经历(30%) / 行业(15%) / 成长(10%) 逐维打分并写理由。
4. **汇总**：加权算出总分，套用推荐阈值（≥4.0 强推 / 3.0–3.9 可投 / <3.0 不投）。
5. **风险块**：独立输出 flag（LOCATION_RISK / LEGITIMACY_RISK / HARD_REQUIREMENT / LOW_GROWTH），不影响总分。
6. **结构化输出**：使用 `04-job-evaluation.md` 第五节定义的输出格式，包含四维明细表、匹配点、风险点、下一步建议。

## 约束

- 所有打分理由必须能回溯到 `cv.md` / `knowledge/` 的真实内容。
- 禁止虚构。缺口标为风险点。
- 不自动投递，结尾明确写"待用户确认"。
