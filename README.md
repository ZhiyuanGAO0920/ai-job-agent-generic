# AI 求职 Agent（通用版）

一个**零依赖、可适配任意候选人与岗位**的 AI 求职评估工作台。四维加权匹配评分、简历定制、批量排序、模拟面试、ATS 校验、投递档案——全部由你自己的「求职画像」驱动，**不内嵌任何特定人物信息**。

## 特性

- **画像驱动**：首次使用在网页「👤 我的画像」填写简历、补充资料、求职偏好、评分权重与阈值。
- **四维加权评分**：技能 / 经历 / 行业 / 成长，权重与推荐阈值可配置（含技术 / 产品 / 运营 / 设计预设，各预设含义有文字说明）。
- **云端画像（多画像）**：画像可保存到服务端，支持多个具名画像切换、跨设备恢复，解决「同浏览器多候选人互相覆盖」与「清缓存丢失」问题。
- **可解释**：每条评分都有回溯到真实资料的理由；独立风险块（地点 / 硬门槛 / 幽灵岗）永不拉低匹配分。
- **诚实约束**：简历定制只重组真实经历，禁止虚构。
- **完整闭环**：评估 → 批量排序 → 简历定制 → ATS 校验 → 模拟面试 → 导出 PDF → 档案·投递追踪。
- **JD 截图 OCR**：粘贴 / 拖拽 / 上传 JD 截图，GLM 视觉自动识别文字。
- **零依赖**：Node 原生 http + 纯静态前端，无需 `npm install`。

## 快速开始

1. **配置 API Key**（真实评分需要）：复制 `server/.env.example` 为 `server/.env`，填入 `DEEPSEEK_API_KEY` 和 / 或 `GLM_API_KEY`。
   - 评估 / 定制 / 面试 / ATS 走 DeepSeek 或 GLM（Anthropic 兼容接口）。
   - JD 截图 OCR 需要 GLM（视觉模型 `glm-4v-plus`）。
2. **启动**：双击桌面 `AI求职Agent-通用版.cmd`，或 `node start.js`（默认端口 3000，自动规避占用端口）。
3. **填写画像**：打开页面 → 右上角「👤 我的画像」→ 填写简历 / 资料 / 偏好 / 评分配置 → 保存。
4. **开始使用**：粘贴 JD（或截图识别）→ 选模式（真实评分 / 批量排序 / 简历定制 / 面试准备）→ 查看结果、存入档案。

> 未配置 Key 也能用「示例预览」模式开箱体验（内置中立演示候选人与 JD）。

## 画像与评分配置

- **简历正文**：真实、完整。评估与定制只基于此与补充资料。
- **补充资料 / 知识库**：可增删改，作为评估与简历定制的真实证据（如某段工作 / 项目经历）。
- **评分配置**：四维权重（自动归一化）与推荐阈值（默认 4.0）。职能预设可一键套用技术 / 产品 / 运营 / 设计权重，选中后展示该预设的权重取向说明。

## 云端画像（多画像 / 跨设备）

在「👤 我的画像」向导最下方「⑥ 云端画像」面板：

- **保存到云端**：输入一个名称（如「我的主画像」「实习版」），把当前画像存入服务端 `data/profiles.json`。
- **切换 / 载入**：点列表里的「载入」即可把某云端画像拉回本机并激活。
- **删除**：点「删除」移除云端画像（不可恢复，需确认）。
- **刷新**：重新拉取云端列表。

这样同一台电脑上的不同候选人可以各有独立画像（不再互相覆盖），换设备 / 清浏览器缓存后也能从云端恢复。

> 画像云端存储为明文 JSON（仅本人服务的本地服务端），不含任何 API Key。若部署到公共服务器，请自行做好访问控制。

## 团队 / 组织默认画像

编辑 `profile/default-profile.json` 可作为组织级默认画像（首次启动向导会加载它）。用户保存后存于浏览器 localStorage，互不影响。

## 安全

- API Key 仅存于服务端 `server/.env`，绝不下发前端。
- 本工具只评估与排序，**绝不自动投递**。

## 与个人版（ai-job-agent）的区别

个人版内嵌了特定候选人的简历与知识库、写死的四维权重；通用版把这些全部外置为可配置画像，任何人都能用自己的信息开箱使用。
