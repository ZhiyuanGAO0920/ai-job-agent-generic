# /tailor — 生成定制简历

## 用法

```text
/tailor <JD 文本 或 URL>
```

## 执行步骤

1. **先评估**：隐式调用 `/evaluate` 的逻辑，得到四维评分与匹配点 / 风险点。
2. **提取关键要求**：从 JD 抽出 5–10 个核心关键词与能力要求。
3. **映射真实经历**：将每个核心要求映射到 `cv.md` + `knowledge/` 中的真实证据。**只重组，不编造。**
4. **生成定制简历**：
   - 围绕匹配点调整项目经历的叙述重点与关键词。
   - 对缺口（风险点）做诚实处理：不虚构，可在"自我评价"中写"学习中/已具备方法论"等真实表述。
   - 输出 ATS 友好格式（纯文本 / Markdown / LaTeX 模板，见上游 `templates/`）。
5. **ATS 自检**：确保联系方式完整、阅读顺序合理、JD 关键词覆盖（不堆砌）。
6. **提交确认**：输出草稿 + verification checklist，等用户确认后编译 PDF。

## 约束（Honesty Rule，绝不违反）

- **禁止虚构任何经历、技能、数据、量化指标。**
- 所有内容必须能回溯到 `cv.md` / `knowledge/` 的真实素材。
- 若 JD 要求某能力候选人不具备，宁可留白或写真实学习状态，不得编造对应项目。
- 不直接对外发送，等人工确认。
